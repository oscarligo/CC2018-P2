# CC2018 - P1

## Proyecto 1 de Gráficas por Computadora

Implementación de un raycaster para simular un entorno 3D.

Demo del juego: <https://youtu.be/WoRHXJPFdbc>

## Controles

- w: moverse hacia adelante dentro del juego.
- w: moverse hacia arriba dentro de los menus.
- s: moverse hacia atras dentro del juego.
- s: moverse hacia abajo dentro de los menuss.
- ENTER: disparar un proyectil.
- ENTER: salir de la pantalla pricipal y pantalla de muerte.
- ENTER: seleccionar un mundo

## Features

- Rotación horizontal con el mouse.
- Disparo de proyectil (presionar ENTER).
- Minimapa que muestra la posición de jugador en el mundo.
- Música de fondo en cada mundo.
- Efectos de sonido.
- Animación en portal y enemigo.
- Pantalla de bienvenida.
- Permite seleccionar entre multiples niveles.
